# 2026-11-11 Runze

## 需求描述

我有很多效果器单块，拿到排练室玩的时候，供电是个大问题：我没有组效果器板因为太贵了，那么每次带一两个效果器和大家分享着玩的时候，就需要想办法给它供电。我现有的硬件可以支持的解决方法有：

1. 用单块电源：需要额外带着电源这个物件，另外电源还需要插在哪里，还要带电源线，总体非常麻烦
2. 用可充电的9v电池接那个转9v圆圈头的小玩意儿接效果器：可充电的9v电池本身是个小众的东西，我担心它的质量问题，别起火给我烧死了，不充电的电池吧，我又非常讨厌耗材，不会去采购9v电池的

因此，我的需求是：是不是可以开发一个小玩意儿，一头接充电宝的typec，一头接效果器的9v入口？
