# 2026-11-11 下单与组装说明

## 1. 下单文件

`hardware/v1-usbc-9v/release/gerber/` 下是一次打包的全部制造文件（KiCad 10 按 JLCPCB 约定命名）：

| 文件 | 用途 |
| --- | --- |
| `*.gbr`（F_Cu / B_Cu / F_Paste / B_Paste / F_Silkscreen / B_Silkscreen / F_Mask / B_Mask / F_Fab / B_Fab / Edge_Cuts） | 嘉立创 PCB 下单：直接全选上传 |
| `*.drl` + `*_drl_map.gbr` | Excellon 钻孔与钻孔图 |
| `V1_USBC_9V-pos.csv` | SMT 坐标（含 BOM 需要的 Ref、Val、Package） |
| `V1_USBC_9V-bom.csv` | SMT 贴片 BOM（Comment / Designator / Footprint / LCSC） |
| `drc.rpt` | KiCad DRC 报告，0 error 才能下单 |

## 2. 嘉立创下单参数

| 项目 | 选择 |
| --- | --- |
| 板子层数 | 2 层 |
| 尺寸 | 约 128 × 62 mm（以 Edge_Cuts 为准） |
| 板厚 | 1.6 mm |
| 阻焊 | 绿色（或任意） |
| 表面处理 | 有铅喷锡（HASL）即可 |
| 最小线宽/间距 | ≥ 6/6 mil（设计按 0.15 mm 约束） |
| 过孔 | 0.6 / 0.3 mm |
| SMT | 经济型贴片（元件都在嘉立创基础/扩展库） |

### 2.1 不需要 SMT 时的采购清单

- PCB 只打板（约几十元 5 片）。
- 元件按 BOM 在立创商城一次配齐；USB-C、DC-005、按键、测试点可手工焊。
- 推荐先只做 **1 片**，不要一次贴 5 片。

## 3. 组装顺序（每步都要先断电、放电）

1. 先焊最容易短路的细间距件：U2（WSON-6）、U4/U6（SOIC-8）、U3（SOT-23）。每焊一个用万用表量相邻引脚无短路。
2. 焊无源件：先电源网络的电容，再电阻。
3. 焊连接器：USB-C 母座（注意四个外壳固定脚全部接 GND）、DC-005、测试点。
4. 焊接后**不要直接接效果器**，先做第 4 节的上电检查。

## 4. 上电检查流程（务必按顺序）

| 步骤 | 操作 | 合格标准 |
| --- | --- | --- |
| 0 | **万用表测 J2 中心针与 GND 是否导通**（中心针必须接 GND）；不通过则重焊/报废，不得接效果器 | 中心针 = GND |
| 1 | 目视 + 万用表二极管档查 VBUS、VIN、VBST、PEDAL 对 GND | 无短路 |
| 2 | 限流电源 5V/100mA 接 USB-C（或接一个能限流的 USB 测试仪） | 空载电流 < 30 mA |
| 3 | 测 VBST 测试点 | 9.0 ± 0.1 V |
| 4 | 测输出测试点 | 9.0 ± 0.1 V（Q2 默认导通） |
| 5 | 接 100 Ω（90 mA）假负载 30 分钟 | 输出仍 9.0 V，U2 温升可接受 |
| 6 | 接 47 Ω（190 mA）假负载 10 分钟 | 输出不低于 8.8 V，无保护动作 |
| 7 | 先用 60 Ω 串入再逐步降到 22 Ω（410 mA）模拟过载 | 超过约 230 mA 后 OC 关断，输出断开，输入电流跌回；拔插 USB-C 后恢复 |
| 8 | 拔掉再插上 | 恢复正常 9V |
| 9 | 效果器前先串 100 Ω 限流测一次"空载漏电压"，确认 < 0.5 V | 无异常 |
| 10 | 最后才接效果器：先用最便宜的一块测试 | 无爆音、无异味、面板灯正常 |

## 5. 使用时注意

- **先接效果器，再插充电宝**：插上即输出，避免带电插拔产生爆音。
- 输出插头必须是 **5.5×2.1 中心负极**；用前用万用表确认本机 DC-005 的中心针接的是 GND。
- 一个充电宝可以同时给两个效果器（用分支线），但总电流不超过 200 mA。
- 整机不要放在密闭小盒里满载长时间运行；U2 是唯一明显发热点。
