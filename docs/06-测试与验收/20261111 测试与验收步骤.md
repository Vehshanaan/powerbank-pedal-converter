# 2026-11-11 测试与验收记录

按顺序做，每步通过再进下一步。任何一步失败都停下来记录，不要带着疑问接效果器。

## 0. 需要的工具

- 可调限流电源（或带电压/电流显示的 USB 测试仪 + 充电宝）
- 万用表
- 假负载：100 Ω / 1 W、47 Ω / 2 W、22 Ω / 5 W（或用电子负载）
- 示波器（可选，看纹波）

## 1. 焊接后、上电前

| 检查项 | 做法 | 通过标准 |
| --- | --- | --- |
| 电源网络短路 | 万用表蜂鸣档：VBUS–GND、VIN–GND、VBST–GND、PEDAL_OUT–GND | 均不导通 |
| 关键节点电压 | 不适用（未上电） | — |
| 焊点 | 放大镜看 U2/U4/U6/U3 引脚无桥连 | 无 |

## 2. 空载上电（限流 5 V / 100 mA）

| 测试点 | 预期 | 实测 | 备注 |
| --- | --- | --- | --- |
| 输入电流 | < 30 mA | | |
| TP1（VBST） | 9.0 ± 0.1 V | | |
| TP2（PEDAL_OUT） | 9.0 ± 0.1 V | | |
| 绿灯 D9 | 亮 | | |

## 3. 带载测试

| 负载 | 输出电流 | 预期 | 实测 |
| --- | --- | --- | --- |
| 100 Ω | 90 mA | 9.0 ± 0.15 V，持续 30 min 不保护 | |
| 47 Ω | 190 mA | ≥ 8.8 V，U2 温升 < 40 K | |
| 22 Ω | 410 mA | 保护动作，输出断开；输入电流回落到 mA 级 | |

## 4. 保护功能

| 场景 | 做法 | 预期 |
| --- | --- | --- |
| 输出短路 | 输出直接短接 2 s | 保护动作、无过热、无焦味；撤掉短路后输出恢复 |
| 过压 | 断开 R5 上端并短暂接 3.3 V（模拟 FB 失效） | 输出 ≤ 12 V 并关断 |
| 拔电 | 带 190 mA 负载拔掉 USB-C | 输出立即消失，再插恢复 |

## 5. 与效果器联调

1. 先用最便宜的一块单块；先插效果器电源线，再插充电宝。
2. 听底噪：与单块原装电源相比，不应出现开关啸叫或低频哼声。
3. 触摸外壳/线材，确认无麻手感（漏电）。
