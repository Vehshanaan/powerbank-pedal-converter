# 独立评审记录

评审方式：多个干净上下文的 subagent（不同提示角色），只读检查。本文件保留原始意见与处理结论。

## A. 电路安全评审（模拟/电源工程师角色）

原始意见（按严重度，节选原文要点）：

1. **致命：按键未接电源**。网表里 K1 两端分别落在 GATE2 与 GND，按下只是把已关断的栅极再拉地，永远无法导通。→ 改为 K1 一端接 VBST、另一端接 GATE2（按下时栅源 0V=导通后松开也保持？不行，需保持）。
2. **致命：无锁存**。故障消失立即恢复，UV 抖动会打嗝。
3. **致命：OV 判据在 VBST，钳位二极管 2×500mW 齐纳在 1.2A 限流下会烧穿成短路**，之后 OV 失效。
4. **致命：拔 USB 时 Q2 栅极悬空**，输出行为不确定。
5. **高：UV 检测的是 VIN(5V)，阈值 8.27V 永远欠压**，上电即锁死无输出。
6. **高：比较器输入可能超过 Vcc**（VBST 崩溃时），开集上拉接到已死的 VBST 导致悬空。
7. **高：过流差分网络阈值 ≈0**：20mR×0.1A×1/51 ≈ 39µV，小于 LM2903 Vos，不可用。
8. **高：U6B 缓冲 OCLT 无上拉**，开集输出悬空，过流永不动作。
9. **中：Q1 S/D 反了**，体二极管方向导致无反灌阻断效果。
10. **中：红色 LED 接在 Q4 集电极**，正常时微亮。
11. **中：DC-005 极性无法从符号判定**，投板前必须实测。
12. **低：VBUS TVS 用 18V 过高**；TPS61170 EP 需要散热过孔；C1 耐压。

## B. 需求/产品评审（产品经理+工程师角色）

1. 方向正确，但可考虑 PD 诱骗 9V、成品升压线、隔离 DC/DC 作对照。
2. VBUS 保护应换 5.6V 单向 TVS；OV/UV 阈值需按比较器实际 VOH 重算。
3. 120mA 对模拟块够用，数字块偏紧；两个效果器共地有地环风险；F2 200mA PTC 与 100mA 负载余量只有 2 倍，偏小。
4. 成果物需要：Gerber（JLC 层名）、Excellon 钻孔、坐标、BOM（补齐全部 LCSC 码）、下单说明、装配说明、测试步骤、线材/外壳图、DRC 报告。悬空引脚必须有 no_connect 标记。
5. 结论：方向可认可为 V1 原型，当前文件不能投板。

## 处理结论（2026-11-11）

- 采纳：5、9、7、8、10、12（VBUS 保护）、F2 加大、no_connect 标记、交付清单。
- 部分采纳：2（改为单稳态 + 拔电复位，而不是复杂锁存）、4（栅极加默认关断下拉）、3（钳位改 SMAJ12A TVS 单只 + 串联限流）。
- 不采纳：A1（按键改为"按住才输出、松开自保持"由单稳态 MKP 电容实现，见最终原理）；
  B2 的 PD 诱骗（用户充电宝不保证支持 PD，且无限流）。
