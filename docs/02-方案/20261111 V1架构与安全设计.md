# 2026-11-11 V1 架构与安全设计

## 1. 目标与非目标

### 1.1 目标

把充电宝的 USB-C 输出（5V，2A 档）转换成效果器需要的 9V 直流，接到效果器的 9V DC 入口（5.5×2.1mm，中心负极）。

### 1.2 非目标（V1 不做）

- 不带电池，不涉及锂电池充电与电芯安全。
- 不做多路隔离输出（一台设备只带一个或两个共地的效果器）。
- 不做 12V/18V 档位。

## 2. 使用场景约束

| 项目 | 结论 | 来源 |
| --- | --- | --- |
| 模拟效果器典型电流 | 4–10 mA（Boss SD-1 / DS-1 标称 4–10 mA） | Boss 官网规格页 |
| 数字效果器典型电流 | 约 30–100 mA（混响、延迟、调音表） | 社区功耗清单，需实测确认 |
| 效果器 9V 口极性 | 中心负极（绝大多数） | 行业惯例 |
| 效果器能承受的电压 | 外围电解电容常见 16V，TL072 总电源绝对值 36V | 元件手册 |
| 9V 口旁路电容常见值 | 47–100 µF | 行业惯例 |

结论：

1. V1 输出能力定 **9.0V / 100mA 连续，150mA 限流**，覆盖大多数单块；数字块若超过限流，设备会先限压、后关断，而不是烧坏。
2. 输出绝对不超过 **10.5V**（期望值 ±3% 内，硬上限 10.5V），即使控制环失效也不越过效果器元件的安全区。

## 3. 方案比较

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| A. USB-C 受电 + 升压到 9V（本方案） | 充电宝通用、无电池安全风险、体积小 | 排练中依赖充电宝；升压效率约 85% | **采用** |
| B. 内置 18650 + 升压 | 不依赖充电宝 | 电芯安全、充电器、认证全部要自己做，成本高 | V2 再评估 |
| C. 现成 9V 单块电源 | 最省事 | 用户明确不要 | 排除 |
| D. 可充 9V 电池 | 便携 | 用户担心质量与起火 | 排除 |

## 4. 系统框图

```text
 USB-C(充电宝5V,2A)
      │ CC1/CC2 5.1k×2  →  申请 5V 2A 档
      ▼
 [D1 防反 / 共模 ] → [F1 自恢复保险 0.5A] → VIN
      │
      ├─ D2 30V TVS（对地）
      ├─ R8 100Ω→C9 10µF → U2 LDO(CJ6211A33 3.3V)
      │        └─ 3.3V：U1 监控芯片、U3 低电量比较器、电源灯、故障灯
      │
      ├─ R12 220k / R17 97.6k → U3 比较器（VIN < 8.14V 判低电量）
      │
      ├─ Q1 P-MOS 反灌阻断（G 由 U1 控制）
      │
      ├─ U4 升压 TPS61170：L1 10µH → D4 SS34 → VBOOST（9V 闭环）
      │        └─ U1 监控芯片监 VBOOST（>10.5V 判过压）
      │
      └─ Q2 P-MOS 输出开关（EN_OUT 默认关断）
               └─ R19 50mΩ 采样 → U3 比较器（>150mA 判过流）
                     └─ [F2 0.25A] → [PTC 0.16A] → DC 插座（中心负）
                                          └─ D5 18V TVS / C13 47µF
```

## 5. 功能模块

### 5.1 USB-C 受电

- CC1、CC2 各接 5.1kΩ 到 GND：源端据此判定 Sink，按 USB BC1.2/Source 规范给 5V 2A。
- VBUS 对 GND 加 **D2（SMBJ30A，30V 钳位）**：充电宝 USB-C 口本身不会输出 20V（不协商 PD 即保持 5V），TVS 只是防止异常源的 ESD/浪涌。

### 5.2 输入保护

1. **F1**：自恢复保险 0.5A（1206，跳闸电流 1A 左右）。输入短路时最先动作，保护充电宝侧。
2. **D1 / 反接**：USB-C 口本身不反接，D1 使用理想二极管不可行（成本），改用 **Q1 P-MOS 反灌阻断**：升压端存电不会倒灌回 USB-C。

### 5.3 升压核心（U4 TPS61170）

- 通过反馈电阻把输出稳定在 9.03V（目标 9.0V）。
- 开关峰值电流限 1.2A（内部），在 5V 输入时允许输出 150mA 以上。
- 内部软启动、逐周期限流、过温关断。
- 详细计算见 `参数计算.md`。

### 5.4 输出开关（Q2）

**这是本设计最重要的安全特征**：输出端在没有明确指令时**不送电**。

- 上电后 Q2 默认关断；需要按一下按键（或短接 1×2 排针 `J_ON`）才会输出。
- 输出状态由 **U1 监控芯片**维持：只要出现以下任一情况，U1 立即释放 Q2 栅极，输出断开：
  1. VIN 出现（低电量比较器判低）→ 断开，避免把不足 9V 的电压送去效果器（效果器此时可能已掉电重启，产生爆音）。
  2. VBOOST 过压（>10.5V）→ 断开。
  3. 输出过流（>150mA 持续约 20ms）→ 断开。
- 断开后可再次按键恢复；不会自动反复重启。

### 5.5 输出端次级保护（与升压环并联，独立动作）

即使升压芯片失控输出 18–30V：

1. **D6–D9 四个 5.1V/1W 齐纳并联**（对 GND，共 20.4V 钳位，约 4W 耗散）：会把 VBOOST 压到 20V 左右。**注意：D6–D9 必须放在 Q2 的输入侧（升压输出端），不能放在效果器侧**，否则故障时钳位会把能量压在效果器上。
2. Q2 在过压判定后断开，效果器只看到已断开的输出。
3. **F2 0.25A 慢熔贴片保险 + PTC 0.16A**：短路时切断。
4. **D5 SMBJ18A**（钳位约 29V）只做 ESD/浪涌，不承担持续故障能量。

### 5.6 状态指示

- **电源灯**（绿色）：3.3V 辅助电源正常。
- **低电量灯**（橙色）：VIN < 8.14V 时亮。
- **输出灯**（蓝色）：Q2 导通、输出已送电。
- **故障灯**（红色）：过压或过流锁存。

## 6. 状态机

```text
上电
  ↓
S0 待机（Q2 关断，输出 0V）
  ├── 按键 → 检查 VIN ≥ 8.14V？是 → S1 送电
  │                          否 → 低电量灯亮，回到 S0
  ↓
S1 送电（Q2 导通，VOUT ≈ 9.03V）
  ├── 输出过流 >150mA×20ms → S2 故障锁存
  ├── VBOOST >10.5V → S2 故障锁存
  ├── VIN < 8.14V → S0（断开，但升级为"欠压锁存"，需 VIN 恢复后按键）
  └── 再按键 → S0
       ↓
S2 故障锁存（红灯亮，Q2 关断）
  └── 拔插 USB-C（VIN 中断 >100ms）→ 复位到 S0
```

故障锁存的原因：防止输出短路后反复打嗝冲击效果器和充电宝。

## 7. 安全设计汇总

| 保护点 | 实现 | 触发/动作 | 保护对象 |
| --- | --- | --- | --- |
| 默认不带电 | Q2 常关，按键/排针强制确认 | 输出 0V | 效果器 |
| 防倒灌 | Q1 P-MOS | VBOOST 有电时 USB-C 无反灌 | 充电宝 |
| 输入过流 | F1 0.5A 自恢复 | 输入合计 >~1A | 充电宝/线材 |
| 输出过流 | R19 50mΩ + U3 比较器 | 150mA → 20ms 关断 | 效果器/线材 |
| 输出硬限压 | D6–D9（4×5.1V 并联）在升压侧 | 20.4V 钳位 | Q2 自身/升压器 |
| 过压关断 | U1 + 延时 | VBOOST >10.5V → 断开 | 效果器 |
| 输出短路 | F2 0.25A + PTC 0.16A | 约 0.3–0.5A 切断 | 全部 |
| 浪涌/ESD | D2、D5、R2 阻尼 | 钳位 | 器件 |
| 欠压 | U3 比较器 | VIN < 8.14V 拒绝/关断 | 效果器（避免掉电重启爆音） |
| 输出空载能耗 | 无固定泄放负载 | 输出断开时无电流 | 电池续航 |

## 8. 已知限制与未验证项

1. 充电宝在低负载（V1 待机电流约 15–20mA）下可能 **自动关断**（多数充电宝有 50–100mA 以下自动关机的特性）。V1 待机时 Q2 到底关、升压停止，总电流很小，需要实测：若出现充电宝关机，可选"唤醒"按键（按下时短接 100Ω 假负载 1s）或更换带小电流模式的充电宝。**V1 先留排针 `J_WAKE` 的焊盘，不装元件。**
2. 8.14V 的低电量阈值假定充电宝输出 5V、升压纹波与二极管压降如上计算；实际以实测为准。
3. 低电量阈值对温度、器件容差有 ±0.3V 偏移。
4. 尚未做 EMC/噪声测试；开关频率高（1.2MHz）且输出对音频敏感，布局见 `PCB布局与走线约束.md`。
