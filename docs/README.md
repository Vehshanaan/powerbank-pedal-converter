# 文档目录

本仓库用于设计一个"充电宝 USB-C 输入 → 效果器 9V 入口输出"的电源适配器（下称"升压线/升压板"）。

## 阅读顺序

1. `01-需求/`：使用场景、约束、用户原始诉求。
2. `02-方案/`：架构选型、方案比较、版本规划（V1 最简安全版、V2 内置电池版）。
3. `03-原理设计/`：电气参数计算、原理图、各保护点的作用与失效后果。
4. `04-元件与BOM/`：选型理由、立创商城/嘉立创可买的 BOM。
5. `05-PCB与下单/`：嘉立创下单流程、PCB 布局走线约束、外壳与线材。
6. `06-测试与验收/`：上电顺序、逐项验证、测试记录。
7. `99-评审临时/`：独立评审的原始意见（过程文件，合并进主体文档后可删）。

## 约定

- 文件名延续"日期 + 主题"（如 `20261111 方案比较.md`），同一目录内按编号排序。
- 参数一律写单位、来源（数据手册 / 计算 / 实测）与适用条件。
- 需求、假设、计算结论、实测结论分开标注，未验证项必须显式列出。
- 本目录只放文档；KiCad 工程、Gerber 等产物在仓库根目录 `hardware/` 下，按版本号分目录。

## 当前状态

- 设计版本：V1（无电池、充电宝直供、默认输出关断）。
- 尚未完成：KiCad 原理图与 PCB 文件、打样、实测。文档中所有"应达到"的指标均为计算值或资料结论，需按 `06-测试与验收/` 实测后更新。
