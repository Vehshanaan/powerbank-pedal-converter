# 2026-11-11 设计说明（V1，最终稿）

一句话：USB-C 插充电宝，立即输出 9V / 200mA 给效果器；三路硬件关断 + 两级硬保护，不依赖任何软件。
用户 2026-11-11 确认：**插上即输出，单口 200mA，不做内置电池。**

## 2. 保护逻辑（全部硬件）

- 输出 P-MOS Q2 栅极默认经 R21 100 kΩ 接地 → **默认导通**；Q3 一旦导通，就把栅极抬到 VBST → 关断。
- 三路比较器（LM2903 ×2）输出开集，经 BAT54S 隔离二极管共同驱动 Q3 基极：**任一路动作即关断**。
  - UV：VIN 分压（100k/100k）低于 4.3 V 稳压管基准 → 动作（防止输入异常低）。
  - OV：VBST 分压（220k/62k）高于 2.5 V 基准 → 动作，同时 Q6 拉低 TPS61170 的 FB（crowbar，升压主动降压）。
  - OC：20 mΩ 采样 → 1k/27k 衰减 → 与 2.5 V 缓冲基准比较 → 动作。
- 硬保护（与上述开关无关）：SMAJ12A 把升压输出钳在 12 V 左右；F2 限制输出电流。
- 拔电：VBST 电容放电后 Q2 栅极仍有 R21 到地，输出断开；Q1 的体二极管朝 VBUS，不会倒灌。

## 4. 已知限制 / 必须实测

1. **DC-005 中心针极性**：封装无法从符号判定，装配后用万用表确认"中心针 = GND"，丝印已标 CENTER NEG.。
2. 输出 200 mA 对模拟块绰绰有余；数字块（混响、延迟）接近上限，超过会触发过流关断。
3. 一个充电宝同时带两块效果器时共地，可能出现地环底噪；本板不做隔离。
4. 阈值、纹波、OC 响应时间都是计算值，必须按 `06-测试与验收/` 实测并记录。
